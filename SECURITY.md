# Security policy

This project touches private local Launchpad data only through a user-chosen, separately installed writer. Treat malformed exports, unexpected database behavior, and data-loss risks as security-relevant issues.

Before relying on this policy, the repository maintainer must enable GitHub private vulnerability reporting in repository settings. Once enabled, report vulnerabilities through that feature. Until then, do not open a public issue for a potential vulnerability; contact the repository owner through their GitHub profile instead.

Do not include a real Launchpad database, app inventory, credential, screenshot, log, or personal filesystem path in any report.
